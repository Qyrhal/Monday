# Contributing

## Key Principles
- All contributions welcome!
- Use bun for the frontend
- Use uv for backend
- Please be meaningful in changes, dont provide useless slop
- Use all tools including AI to your avail.
- Meaningful commits and verbose descriptions (ignore the first commit on main)
- Format the code: uvx ruff format. Frontend doesnt have a formatter and linter 
- please provide documentation for changes in code, or ambiguous functions/methods
